# Prompt Forge

AI Prompt Forge — build, optimize and score prompts for IT & engineering teams. Version prompts, A/B test variants and ship the winner. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/prompt-forge/

## About
Prompt Forge is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **Developer & LLM Tools**.

## Features
- Prompt versioning with diff history
- A/B testing across models with quality scoring
- Template library for common IT & engineering tasks
- Exportable prompt packs for teams
